# ANN-Classification-Churn-Modelling-
End to End ANN-based customer churn prediction with TensorFlow and Streamlit. This project covers data preprocessing, model training, serialization, and a simple web interface for real-time predictions.
*Tech Stack*

*Python* – Core programming language used for data processing, model training, and deployment logic.

*TensorFlow / Keras* – Used to build, train, and evaluate the Artificial Neural Network model.

*Scikit-learn* – Handles data preprocessing tasks such as label encoding, one-hot encoding, feature scaling, and train–test splitting.

*Pandas & NumPy* – Used for data manipulation, cleaning, and numerical operations throughout the pipeline.

*Streamlit* – Powers the interactive web application for real-time customer churn prediction and model inference.
